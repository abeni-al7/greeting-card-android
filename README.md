# Greeting Card

The first Compose app from the course: a single `Text` greeting ("Hi, my name is ...!") on a colored surface.

Built while following Google's [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) course (the "Greeting Card" codelab).

## Features

- One screen with a greeting composable and a Compose preview

## Built with

- Kotlin, Jetpack Compose, Material 3
- `Scaffold`, `Surface`, `Text`, `@Preview`
- Min SDK 24, target/compile SDK 35

## Run it

1. Open the project folder in Android Studio and let Gradle sync.
2. Run the `app` configuration on an emulator or device (Android 7.0 / API 24 or newer).

Or, with a device or emulator connected:

```sh
./gradlew installDebug
```
